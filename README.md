## Contents
```
index.html                          Home: student pass, profile, departures board of six PS, project context, SMART-TRACK feature

assets/fonts/                       Self-hosted Archivo, Albert Sans, DM Mono (woff2)
```

All paths are relative; no build step, backend or external requests.

## Preview
Open `index.html`, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy
- **Netlify:** drag this folder onto app.netlify.com/drop.
- **GitHub Pages:** push the contents → Settings → Pages → deploy from branch, root.
- **Vercel / any static host:** upload as-is (framework "Other", no build command).
